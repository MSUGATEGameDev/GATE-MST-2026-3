# Pushbox
**By:** John L

### Instructor Thoughts
Building a game out of glitches was a funny idea, reminiscent of games like GoatSimulator and Garry’s Mod. It was fun to try to bounce the player out the top of the map, or crash the game with the influx of enemies. 

### Tweaks we made post-class
In order to keep some of your intentionally-glitched features working, we weren’t able to implement all of the bug-fixes we added to the other projects. 

### Moving Forward
There’s not a ton to suggest moving forward, but as we add more features to the template, it would be great to see how you can bug out those features as well.
